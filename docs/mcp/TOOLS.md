These are MCP tool calls after initialization and authentication, not standalone HTTP requests. Never reuse example revisions or IDs in production. The write example changes a lead when supplied valid production values.

### Inspect connection

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "crm_get_access",
    "arguments": {}
  }
}
```
